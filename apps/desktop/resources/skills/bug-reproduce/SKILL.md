# Bug Reproduce

## 目标

先证明问题真实存在，再解释根因。不要从猜测开始改代码。

## 步骤

1. 收集输入、环境、复现步骤、期望结果和实际结果。
2. 用最小命令或最小文件复现问题，记录完整错误和退出码。
3. 缩小范围：入口 → 数据 → 核心逻辑 → 外部依赖 → 持久化。
4. 找到根因后再修改；只改与问题相关的最小范围。
5. 重跑复现用例和相关测试，确认原问题消失且没有引入回归。
6. 无法复现时说明尝试过的条件，不假装修复。

## 输出

- 复现条件和证据。
- 根因与修改点。
- 验证命令和结果。
- 剩余风险或无法复现的原因。
