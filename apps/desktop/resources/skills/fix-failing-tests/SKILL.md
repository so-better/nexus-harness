# Fix Failing Tests

## 目标

让真实失败消失，同时保持测试有效。不要删除测试、全局跳过或关闭 lint 规则来制造通过。

## 步骤

1. 运行最小失败集合，记录命令、用例、错误和退出码。
2. 判断失败来自实现错误、测试预期错误、环境问题还是偶发问题。
3. 阅读相关实现、调用方和测试，定位最小根因。
4. 优先修实现；确需改测试时说明原测试为什么错误。
5. 先跑目标测试，再跑相关测试和项目规定的检查。
6. 失败无法修复时保留证据并说明剩余问题，不假装通过。

## 输出

- 失败原因。
- 修改点与影响范围。
- 验证命令和结果。
- 未修复项和下一步。
