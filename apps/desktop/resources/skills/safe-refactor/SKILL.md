# Safe Refactor

## 目标

在不改变外部行为的前提下改善结构。重构和功能变更分开处理。

## 步骤

1. 明确重构边界和不变行为；有歧义先询问。
2. 找到现有测试和验证命令；覆盖不足时先补最小行为测试。
3. 制定小步计划，每一步只做一种结构调整。
4. 每次修改后运行相关类型检查、测试和 lint，失败先修复再继续。
5. 保持公开接口、事件格式、权限和持久化契约稳定。
6. 不自动执行 commit/push；需要版本操作时由用户明确要求。

## 输出

- 结构变化和保持不变的行为。
- 每步验证结果。
- 风险、回滚方式和后续建议。
