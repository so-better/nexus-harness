# Token Efficient Workflow

## 目标

减少无关内容进入模型上下文，但不牺牲正确性、证据和必要验证。

## 步骤

1. 先明确任务和验收标准，避免带着模糊目标反复探索。
2. 优先用 glob、grep、目录摘要定位，不先读取整个仓库。
3. read_file 只读必要区段；同一文件不要重复读取。
4. 工具输出只保留结论、路径、错误码和待办，长日志落 Artifact。
5. 用路径、ID 和摘要引用已有内容，不重复粘贴。
6. 按项目门禁先运行目标测试，再执行相关检查；不得跳过项目要求的完整验证。
7. 上下文变长时主动总结并压缩，保留目标、决策、文件、错误和未完成项。
8. 不伪造结果，不因省 token 跳过关键审批或验证。

## 输出

- 使用的检索范围和结论。
- 未展开或待确认的内容。
- 节省上下文时保留的关键证据。
